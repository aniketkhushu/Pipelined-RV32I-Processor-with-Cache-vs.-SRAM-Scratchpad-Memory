# Pipelined-RV32I-Processor-with-Cache-vs.-SRAM-Scratchpad-Memory
5-stage pipelined RV32I processor implemented in Verilog with a hardware-managed Data Cache and software-managed SRAM Scratchpad Memory (SPM), featuring custom DMA, hazard detection, forwarding, and FPGA deployment on the Zybo Z7-10.
